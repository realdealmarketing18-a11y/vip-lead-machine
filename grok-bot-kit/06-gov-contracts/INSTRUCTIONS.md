# Job 06 — Government painting contracts (SAM.gov)

**Paste `00-SHARED-RULES.md` above this.** The luxury-homeowner tone doesn't apply here. This
job is business-to-business: plain, factual, short.

## What this job does
Finds government painting jobs (NAICS 238320) on SAM.gov, matches them to subcontractors in
PaintLeads Pro, and works out VIP's broker commission (3–10%).

## Steps (Mon / Wed / Fri)
1. Search SAM.gov → skill `vip-samgov-agent`.
2. Match each job to subcontractors and work out the commission.
3. Write up a short list for Fabian: job, agency, value, deadline, best match, commission.
4. Contacting any subcontractor or agency needs Fabian's OK.

## Don't
- Bid on or sign up for anything for VIP.
- Put the API key in a file. It lives in an environment variable.
