AGENT #6

City Research Agent — "VIP Market Intelligence"

RoleResearches each target city/community — builds market profiles for all agents TriggerNew community added to queue, or quarterly refresh Outputmarket_profile.json, demographics.json, competitors.json, content_angles.json ToolsApify (Zillow), Google Maps API, Census API, Yelp Fusion, Google Trends

4 Data Layers Per Community

Layer 1: Demographics & Wealth Profile

Median income, home value, ownership rate, age, education, top occupations, vehicle profile, lifestyle signals (golf, private schools, wine clubs, home renovation)

Used by: Copywriter (language matching), Web Design (imagery selection), Video Scripts (demographic resonance), Lead Gen (scoring weights)
Layer 2: Real Estate & Property Intelligence

Total homes, recent sales, price range, architectural styles, exterior materials, home age, paint cycle indicator, HOA name + color restrictions, renovation permits

Used by: Lead Gen (filtering homes needing paint), Copywriter ("Your home was built in 2012..."), Web Design (HOA badge), Pricing (material adjustments)
Layer 3: Local Competitor Scan

For each local competitor: name, website, Google rating, review count, services, visualization capability (YES/NO), price positioning, marketing channels, weaknesses

Used by: Copywriter ("only company in [Community] that..."), Ad Manager (bid on weak competitor keywords), Video Scripts (reference the visualization gap)
Layer 4: Content Angles & Seasonal Hooks

Climate data (UV index, sunny days), seasonal painting hooks, community events, local hashtags, Facebook/Nextdoor groups, local influencers, hyper-specific pain points

Used by: Video Scripts (seasonal commercials), Copywriter (urgency angles), Ad Manager (scheduling), Outreach (timing around events)

Full Workflow

TRIGGER: New community added to priority queue │ ▼ STEP 1: AUTOMATED DATA PULL Census API → Zillow/Apify → Google Maps → Yelp → Google Trends → Weather │ ▼ STEP 2: COMPETITOR DEEP DIVE For each local painter: website check, visualization? services, reviews, channels │ ▼ STEP 3: CONTENT ANGLE GENERATION Demographics + climate + competitor gaps → seasonal hooks, hashtags, influencers │ ▼ STEP 4: COMPILE MARKET PROFILE Merge all layers → Opportunity Score 1-10 (+3 high values, +2 ownership, +2 no viz competitor, +1 HOA, +1 sales velocity, +1 aging paint) │ ▼ STEP 5: DISTRIBUTE → Copywriter, Web Design, Video Scripts, Lead Gen, COO │ ▼ STEP 6: QUARTERLY REFRESH (every 90 days)
