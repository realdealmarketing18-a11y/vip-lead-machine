🗺️ Step-by-Step Launch SOP

Your complete operating procedure for building, customizing, and publishing a new city sales page — from first WordPress login to live indexed page. Follow this once and you'll be able to repeat it in under 30 minutes per city.

Phase 1 — One-Time WordPress Setup
Do this once. Never again.
⏱ ~45 min
✓

Install Elementor Free

WordPress Admin → Plugins → Add New → search "Elementor Website Builder" → Install & Activate. No account required for Elementor Free.

2

Install "Duplicate Page" Plugin

Plugins → Add New → search "Duplicate Page" (by mndpsingh287, 5M+ installs) → Install & Activate. This lets you clone any page with all its Elementor content in one click — critical for the city page workflow.

3

Install "Better Search Replace" Plugin

Plugins → Add New → search "Better Search Replace" (by Delicious Brains) → Install & Activate. This searches all Elementor widget content database-wide and replaces tokens like {{CITY}} with actual city names — in one operation across every widget on the page.

💡 Why this matters: Elementor stores content in the WordPress database, not in plain text files. Normal "find and replace" won't reach widget content. Better Search Replace does.
4

Install WPForms Lite (Lead Capture)

Plugins → Add New → search "WPForms Lite" → Install & Activate. Create your contact form:

  1. WPForms → Add New → "Simple Contact Form" template
  2. Add fields: Name, Phone, Email, Service Interest (dropdown), Project Description (textarea)
  3. Settings → Notifications → Set email to realdealmarketing18@gmail.com
  4. Save. Copy the shortcode: [wpforms id="X"] — you'll use this in Elementor
5

Set Elementor Global Colors

Elementor → Site Settings → Global Colors. Add these 4 colors with these exact names:

NameHex CodeUse
VIP Orange#E8660AButtons, accents, highlights
VIP Gold#C8960CSecondary accents, borders
VIP Navy#1a1f4eBackgrounds, headings
VIP Dark Text#222222Body text
6

Set Elementor Global Fonts

Elementor → Site Settings → Global Fonts:

  • Primary Font: Montserrat (for headings) — Weight: 800
  • Secondary Font: Open Sans (for body text) — Weight: 400
  • Text Font: Open Sans 400 (body paragraphs)
  • Accent Font: Montserrat 700 (buttons, labels)
7

Install SEO Plugin (Rank Math Free or Yoast)

Plugins → Add New → "Rank Math SEO" (recommended, more features free) → Install & Activate. This adds a meta title, meta description, and keywords field to every page — critical for each city page's SEO. You'll fill these in per city using the token values from your automation output.

8

Install Node.js on Your Computer (for automation)

Visit nodejs.org → click the big green LTS button → download and install. Once done, open a Command Prompt (Windows) and type node --version — if you see a version number, you're good to go.

ℹ️ What Node.js does: It lets the city automation script (VIP_CityPage_Generator.js) run on your computer and generate pre-filled city HTML files automatically each morning.
2
Phase 2 — Build the Master Template in Elementor
Build this once. Clone it 9 times.
⏱ ~3 hours (once)
1

Create the Master Template Page

WordPress Admin → Pages → Add New. Title: VIP Sales Page — MASTER TEMPLATE. Set Status to Draft (never publish this one). Set Page Layout to Elementor Full Width or Canvas (removes header/footer for full design control). Click "Edit with Elementor".

2

Open the VIP_SalesPage_Master_Template.html as Reference

Open the master HTML file in your browser (double-click the file). This is your visual guide for exactly how each section should look. Keep it open on a second monitor or in another browser window while building in Elementor.

💡 Best approach: Open the HTML template and the Elementor editor side by side. The HTML file shows you exactly what to build — copy text directly from it into Elementor's widget fields.
3

Build All 12 Sections

Follow the VIP_Elementor_Build_Guide.html (your widget-by-widget instruction manual) to build each section. Work in order from Section 1 (Hero) to Section 12 (Project Scope + Final CTA). Use token placeholders everywhere — {{CITY}}, {{HOMEOWNER_1_NAME}}, etc. — in the actual text of your widgets.

💡 HTML Widget shortcut: For complex sections (the process steps grid, testimonial cards, comparison table, service cards), just use Elementor's HTML widget and paste the styled HTML code directly from the master template file. It's faster than rebuilding with individual widgets and looks identical.
4

Set Up Mobile Responsiveness

Click the tablet/phone icon at the bottom of the Elementor panel to switch to tablet/mobile view. Adjust font sizes and paddings for mobile breakpoints (anything that looks too large). Elementor Free's auto-stacking handles most of the work — focus on font sizes and padding on mobile.

ElementDesktopMobile

Section Padding (v)80px48px
Section Padding (h)40px16px
5

Preview & Fix

Elementor → Preview Changes → open on desktop and mobile. Check: all sections visible, buttons work, text tokens are visible (e.g. {{CITY}} shows as literal text — good). Save the page. Keep it in Draft — this is your master, never publish it directly.

Phase 3 — Daily City Page Launch Workflow
Repeat this for each of the 9 communities
⏱ ~30 min per city
1

Check the Morning Automation Output

Claude's scheduled task runs at 7:00 AM M-F and generates a city HTML file. Find it in your outputs folder:

// Location on your computer: C:\Users\Owner\Documents\Claude\Scheduled\ // File name example: VIP_Rancho_Cucamonga_SalesPage_20260421.html

Open this file in your browser. It has all the city-specific text already filled in — review it quickly to confirm it looks right.

2

Clone the Master Template in WordPress

WordPress Admin → Pages → hover over "VIP Sales Page — MASTER TEMPLATE" → click "Duplicate This" (from the Duplicate Page plugin). A new draft page appears at the top of your Pages list titled "Copy of VIP Sales Page — MASTER TEMPLATE".

Replace All Tokens (Better Search Replace)

WordPress Admin → Tools → Better Search Replace. For each token, run a replacement:

{{STATE}}CA

⚠️ Important: In Better Search Replace, make sure "Run as dry run?" is unchecked before clicking Run. Also select the correct tables — at minimum select wp_postmeta and wp_posts.
💡 Faster method: The automation output file includes all the token values pre-filled for each city. Just copy/paste them directly from the file into Better Search Replace.
5

Add SEO Copy (Open Elementor → Section 12)

Open the cloned page in Elementor. Scroll to Section 12 (Project Scope / SEO block at the bottom). Click the SEO Text Editor widget. Paste the SEO_INTRO and SEO_BODY text from your morning automation output file. Save.

6

Set Meta Title, Description & Keywords (Rank Math)

Scroll down on the page edit screen — you'll see the Rank Math SEO block below the editor. Fill in:

  • SEO Title: House Painting Rancho Cucamonga, CA | Free Color Visualization | VIP Premier
  • Meta Description: (145 chars max) VIP Premier Painting serves Rancho Cucamonga with premium exterior & interior painting. Free custom color visualization. Licensed & insured. (909) 312-5400.
  • Focus Keyword: painting contractor rancho cucamonga
💡 Your automation script pre-generates all three of these for each city. Just copy from the output file — no writing needed.
7

Publish the Page

Change Status from Draft → Published. Click Update/Publish. Your city page is now live at https://viphomepainting.com/house-painting-rancho-cucamonga-ca/

8

Submit to Google Search Console

If you have Google Search Console set up for viphomepainting.com: GSC → URL Inspection → paste your new page URL → "Request Indexing". Google will typically crawl it within 24-48 hours.

ℹ️ Don't have Search Console yet? Go to search.google.com/search-console → Add Property → enter viphomepainting.com → verify via DNS or meta tag. It takes 5 minutes and is critical for SEO tracking.

Phase 4 — Activate YouTube Videos
Do this once per video when you upload to YouTube
⏱ ~5 min per video
1

Upload your video to YouTube

Go to youtube.com → click your profile → YouTube Studio → Create → Upload Video. Upload your video file. Set title, description, thumbnail. Publish as Public or Unlisted.

2

Copy the Video ID

On the video page, look at the URL: youtube.com/watch?v=dQw4w9WgXcQ — the bold part after ?v= is your Video ID. Copy it.

3

Update Each City Page in Elementor

For each published city page: Pages → Edit with Elementor → find the Video widget for that slot → Content → change URL from the placeholder to https://www.youtube.com/watch?v=YOUR_VIDEO_ID → Save.

💡 Use Better Search Replace: Once you have a video ID, you can use Better Search Replace to update VIDEO_1_PENDING → dQw4w9WgXcQ across ALL 9 city pages at once — one operation, all pages updated.
