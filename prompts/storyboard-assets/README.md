# VIP Premier Painting — Master Creative Strategy Folder

Master creative strategy folder for VIP Premier Painting video content production.

**Three systems:**
- `episodes/` — HGTV-style story templates + 3-step funnel structure
- `render-prompts/` — Higgsfield production library (image + video prompts)
- `video-bible/` — Script-locked, scene-by-scene shot plans

Every folder is organized per-episode so the system clones cleanly across 15 target communities.

All Higgsfield prompts are validated against `.claude/skills/higgsfield/` (MCSLA formula, seedance_lint preflight) before generation.

**Episode 1 baseline:** Douglas & Sheri | 8273 North Fontana CA | Palette: Gateway Gray + Tricorn Black + Origami White | 5 Higgsfield credits total.

Per-episode subfolders hold: `storyboard` (scene map), `renders` (generated outputs + prompts), `script` (word-for-word narration).
