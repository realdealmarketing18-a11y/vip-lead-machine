## How to Use This Document

1. Take 2–3 clean exterior photos of Douglas & Sheri's house first. Straight-on, no cars, morning or overcast light preferred.
2. Open Higgsfield on iPhone. Upload their house photo. Run prompts A through K in order — each one builds on the last.
3. Replace every `[orange placeholder]` with details from their actual home before running the prompt.
4. Save each render with the letter label (`A.jpg`, `B.jpg`...) to your Camera Roll. Import to CapCut in the same order for assembly.
5. Scene tags on each card tell you exactly which scene in the script that render feeds — no guessing in CapCut.
