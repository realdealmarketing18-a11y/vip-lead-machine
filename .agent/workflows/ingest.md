# Ingest New Source

When Fabian drops a file in 01-Raw-Sources, run this workflow:

1. Ask for filename if not specified
2. Read the file thoroughly
3. Identify all core concepts and entities
4. Scan 02-The-Wiki via index.md for related pages
5. Update related pages with new insights + [[wikilinks]]
6. Create new wiki pages if needed
7. Update index.md with new pages + one-line summary
8. Append timestamped entry to log.md
9. Flag contradictions in log.md
10. Report: list all wiki pages updated/created

Compounding rule: One new source updates 10-15 existing pages.
