# Create New Episode

Triggered when client project is ready for content creation.

INPUT NEEDED FROM FABIAN:
- Client names and code (e.g., DS-001)
- Property address and style
- Chosen color palette (body/trim/accents)
- Upsells selected
- Alternate palette names

STEPS:
1. Create 03-Episodes/[client-code]/ folder
2. Generate script.md (8 scenes, word-for-word)
3. Generate render-queue.md (7 renders, copy-paste prompts)
4. Generate storyboard.md (frame-by-frame)
5. Generate sales-page.md (WordPress-ready copy)
6. Generate email-sequence.md (3-touch)
7. Generate ad-brief.md (15-sec + 60-sec)
8. Log completion to log.md
9. Update index.md with new episode

RENDER ORDER: C → K → G → D → E
