Elementor Free Build Guide

Build the master template once in Elementor Free. Clone it for each of your 9 communities. This guide maps every section to exact widget settings — no guessing required.

Builder: Elementor Free
Host: Hotstinger / WordPress
Sections: 12
Communities: 9
Build Time: ~3–4 hours (once)

⚙️ Before You Start — Setup Checklist

  • ☐
    Install Elementor Free — WordPress Admin → Plugins → Add New → Search "Elementor" → Install & Activate
  • ☐
    Install Google Fonts plugin — "Google Fonts for Elementor" or use Elementor's built-in font list (Montserrat & Open Sans are both in Elementor's default font list)
  • ☐
    Set Global Colors — Elementor → Site Settings → Global Colors → Add the 4 brand colors below. You'll select them by name inside every widget.
  • ☐
    Set Global Fonts — Elementor → Site Settings → Global Fonts → Primary = Montserrat (headings), Secondary = Open Sans (body)
  • ☐
    Create a blank page template — Add New Page → "VIP Master Template" → Edit with Elementor → Set Page Layout to "Elementor Full Width" (removes sidebar)
  • ☐
    Disable page title — In Elementor canvas: Settings gear icon → Hide Title = Yes
  • ☐
    Have the master HTML template open in a browser tab as your copy reference (VIP_SalesPage_Master_Template.html)

📅 Daily City Page Routine (Once Template is Built)

After your master template page exists in WordPress, follow these steps each morning to launch a new city page:

  • ☐
    Step 1: Open the automated HTML output from Claude (e.g. RanchoCucamonga_SalesPage.html — generated by the city automation script)
  • ☐
    Step 2: In WordPress admin → Pages → find "VIP Master Template" → Hover → click Clone (use "Duplicate Page" plugin) or right-click → Duplicate in Elementor
  • ☐
    Step 3: Rename the cloned page: e.g. "Painting Company {{CITY}} CA | VIP Premier Painting"
  • ☐
    Step 4: Set the URL slug: e.g. /house-painting-rancho-cucamonga-ca/
  • ☐
    Step 5: Open in Elementor → use Ctrl+F / Find & Replace (or Better Search Replace plugin) to swap all {{CITY}} tokens to the actual city name throughout the page
  • ☐
    Step 6: Paste the SEO copy from the automation output into the SEO block (Section 12C)
  • ☐
    Step 7: Update meta title + description in the page SEO settings (use Rank Math or Yoast Free)
  • ☐
    Step 8: Publish page. Add to your sitemap. Done ✅
