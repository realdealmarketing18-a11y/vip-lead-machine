## STEP 1 — Configure API Keys (5 minutes)

You need three keys active for the full pipeline:

### Firecrawl (for live competitor + Zillow research)
1. Go to firecrawl.dev → sign in → copy your API key
2. In Claude Cowork settings → Environment Variables → add:
   ```
   FIRECRAWL_API_KEY = fc-xxxxxxxxxxxxxxxx
   ```

### WordPress (for auto-publishing pages)
1. In your WordPress dashboard → VIP Settings → copy your `VIP_AGENT_KEY`
2. Add to Claude Cowork environment:
   ```
   VIP_AGENT_KEY = your-key-here
   VIP_WP_BASE = https://viphomepainting.com/wp-json/vip/v1
   ```

### Gmail (for morning briefing emails to yourself)
1. In Claude Cowork → Integrations → Gmail → authenticate with realdealmarketing18@gmail.com

## STEP 5 — Video Production Flow

Once scripts are written, here is how video gets made:

```
Video Script → Higgsfield (renders the visual scenes as AI video clips)
            → Seedance 2.0 (assembles clips + adds VO + music)
            → ffmpeg (final encode + export)
            → Output: MP4 ready for Meta/YouTube/TikTok
```

For each city's 4 videos, give Higgsfield the prompts from the Production Brief file.
The prompts are pre-written in `outputs/video-scripts/[city]-production.md` (generated by Agent 5).

## TROUBLESHOOTING

**Firecrawl returns no results:**
Some competitor sites block scrapers. Note the URL, skip, and proceed with available data.

**WordPress API returns 401:**
VIP_AGENT_KEY may have expired. Check WP dashboard → regenerate key → update env variable.

**Agent produces off-brand copy:**
Any mention of "affordable," "cheap," "AI," or "automated" in outputs = flag and rewrite.
The brand rules in CLAUDE.md are non-negotiable.

**Higgsfield prompts producing wrong style:**
Add "luxury real estate photography quality" and "no stock photo aesthetic" to every prompt.
Specify the exact architectural style and city in every Higgsfield call.
