# Sales Page UI Kit — VIP Home Painting

The mobile-first sales page recreation. Mirrors the 12-section layout from `reference/Sales-Page-Copy-Template-1.md`, using the brand tokens defined in `../../colors_and_type.css`.

**Open `index.html`** to see the full click-thru prototype.

## Components (inline in `index.html`)
- `<Header>` — sticky logo header with blur backdrop
- `<Hero>` — overline, H1 with orange accent, avatar pill, video, CTA, twin gold badges
- `<Why>` — circle "?" badge, video, gold checklist
- `<Process>` — numbered gold step circles
- `<CaseStudy>` — avatar pill, gold case tag, video w/ BEFORE/AFTER, drop-cap, labeled details, CTA
- `<WarrantyHero>` — single gold-laurel warranty badge centered
- `<Pillars>` — 4 numbered offers
- `<WhatWeDo>` — checklist + 2x2 photo grid
- `<Reviews>` — 4 stacked Google review cards
- `<Stats>` — 3 trust cards
- `<Services>` — 3 service blocks with image, title, body, "Learn More"
- `<ProjectScope>` — progress bars + final CTA
- `<FinalCTA>` — navy footer with primary CTA
- `<StickyCTABar>` — bottom-fixed mobile CTA
- `<LeadModal>` — popup form with photo upload (every CTA opens this)

## Conventions
- Max content width 520px, centered.
- Alternating section backgrounds: white / beige / white / navy.
- All shadows navy-based.
- Fraunces for every headline; Inter for everything else.
- No emoji. No "AI" anywhere in copy.
