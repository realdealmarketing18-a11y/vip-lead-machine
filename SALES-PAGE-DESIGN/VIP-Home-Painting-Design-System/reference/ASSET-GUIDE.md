## File Naming Convention
```
[section]-[descriptor]-[variant].[ext]

Examples:
  hero-bg-desktop.webp
  ba-newport-01-before.jpg
  ba-newport-01-after.jpg
  team-fabian-headshot.jpg
  testimonial-sm-newport-photo.jpg
  icon-paintbrush-orange.svg
```

## Image Optimization Checklist
- [ ] Hero images: WebP, under 400KB
- [ ] Gallery photos: WebP, under 200KB each
- [ ] Before/After pairs: WebP, under 300KB each
- [ ] All SVGs minified (remove unnecessary metadata)
- [ ] Headshots: JPEG 85% quality, under 100KB
- [ ] All images have descriptive alt text defined in the HTML
