🚀 Setup Guide — What To Do Right Now

1
Approve the Tools (Critical — Do This First)
Go to the Scheduled section in Claude's sidebar. Click each of the 5 tasks → hit "Run now" once. This pre-approves the web search and file tools so future automated runs never pause waiting for permission.
2
Create Output Folders
The agents save files to subfolders inside your outputs folder. These are created automatically on first run, but you can create them now:
outputs/city-research/ → city profiles
outputs/sales-pages/ → sales page HTML files
outputs/video-scripts/ → script packages
outputs/leads/ → hot leads + outreach emails
outputs/reports/ → morning + weekly reports
3
Your Morning Routine (8:00 AM)
When you wake up, check your Cowork notifications. The morning briefing agent will have already told you exactly what was built and what 3 things need your attention. Review and approve outputs before they go live.
4
Review Sales Pages Before Publishing
Each sales page HTML file opens in your browser. Review the copy, check community-specific details are correct, then paste into WordPress via the Landing Page Agent. Phone number should always read: (909) 312-5400
5
Hand Video Scripts to Your Video Editor / Higgsfield
Video script files in outputs/video-scripts/ are production-ready. Give The Hook and The Story scripts to your video editor first — these drive the most traffic. Use Higgsfield Nano Banana 2 to render the visualization reveal scenes.
6
Send Hot Lead Outreach Emails Daily
Check outputs/leads/hot-leads-[date].md each morning. These are pre-written, ready to send. Copy → paste into Gmail. Each email already has the homeowner's name, address, architectural style, and community name filled in.
7
Monday Morning = Strategy Review
Every Monday at 7 AM, your weekly report is waiting. Read it before you start the week. It shows the full 9-community progress tracker, revenue math, and your top 5 priorities. This is your business compass.
